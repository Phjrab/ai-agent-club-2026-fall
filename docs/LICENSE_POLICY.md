# 라이선스와 재사용 범위

이 저장소와 GitHub Pages에는 1회차 초안이 공개된다. 코드와 강의 콘텐츠의 배포 라이선스는 아직 선택되지 않았다. `course.config.json`의 `codeLicenseDecision`과 `contentLicenseDecision`을 임의로 변경하지 않는다. 공개 열람이 별도의 재사용 허가를 뜻하지는 않는다.

- **프로젝트 코드:** 발표 엔진, 빌드·검증 스크립트, 템플릿은 작성자가 라이선스를 정하기 전까지 별도 허가 없이 재배포하지 않는다.
- **강의 콘텐츠:** `brief.md`, `deck.json`, 한국어 대본, 포트폴리오 문안도 별도 결정을 기다린다. 발표자가 제공한 경험은 독립 검증된 성능 자료로 재사용하지 않는다.
- **제3자 자산:** Pretendard 1.3.9는 패키지의 `dist/LICENSE.txt` 고지를 따른다. 이 프로젝트는 설치 시 패키지에서 글꼴을 복사하며 글꼴 파일은 Git에 넣지 않는다. Chart.js, KaTeX, Prism.js, Mermaid 등 npm 의존성은 각 패키지의 자체 라이선스를 따른다.
- **사용자 제공 요금제 캡처:** 발표자는 2026-09-25 제공한 ChatGPT·Claude·Google AI 요금 페이지 원본 캡처 세 장을 크롭·합성·수정 없이 공개본과 향후 개정본에 그대로 사용하는 것을 허용했다.
- **영상과 링크:** 지정 YouTube 영상은 원본 링크만 제공한다. 영상 파일·썸네일을 저장소나 HTML 패키지에 복제하지 않는다. 외부 문서·그림도 출처 URL만 기록한 항목은 원본 사용 허가로 간주하지 않는다.

공개 저장소의 `deck.json`에는 한국어 발표 대본이 포함된다. GitHub Pages의 학생용 발표 화면에는 대본을 넣지 않는다. Pages에는 PDF·PPTX·DOCX 내보내기를 올리지 않는다. 코드·콘텐츠의 재사용 라이선스는 작성자가 별도로 결정할 수 있다.
