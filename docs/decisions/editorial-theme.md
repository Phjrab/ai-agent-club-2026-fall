# 02 에디토리얼 발표 테마

## 결정

2026년 가을 강의의 공통 발표 화면과 학기 포트폴리오에 MONO STAGE 02 에디토리얼을 적용한다. 현재 구현의 색은 종이 `#F3F0E7`, 깨끗한 정보 면 `#FCFBF8`, 잉크 `#151512`, 구분선 `#C8C5B9`이다. Pretendard 400/600/700과 1920×1080 논리 캔버스, 하단 번호, HTML 발표 엔진은 유지한다.

사용자가 선택한 시안은 종이와 잉크의 대비, 비대칭 여백, 큰 제목, 얇은 선, 겹친 콜라주다. 기존의 장식 금지 문구와 흰 배경 규칙은 이 테마의 표지·전환·포트폴리오 hero에 한정해 개정했다. 본문의 표·스크린샷·도식에는 적용하지 않는다. 고정된 `deck.json` 레이아웃을 바꾸지 않고 렌더러의 `data-editorial-layout`으로 표시 계층을 구분한다.

## 재사용 규칙

1. 다음 회차의 brief/deck/원본 이미지·출처·발표 메모를 먼저 만든다. 빌드가 `src/themes/editorial/theme.css`와 `assets/collage.webp`를 자동으로 private/public 출력에 포함한다.
2. 표지는 큰 제목과 대비되는 단색 면을 쓰고, 학기 포트폴리오 hero에는 장식 콜라주를 쓴다. 비교는 동일 축과 가는 선, 과정은 번호와 연결 순서, 표는 행·열, 영상은 원본 제목·순서·링크를 우선한다. 화면별 `layout`은 콘텐츠 의미를 나타내는 기존 enum을 사용한다.
3. 정보 Figure·제품 로고·가격 캡처·영상 썸네일은 회전, 왜곡, 색 제거, 의미 있는 크롭을 하지 않는다. 설명 그림에 콜라주를 근거 이미지로 섞지 않는다. 장식 자산은 실제 동아리 사진이나 교육 성과의 증거가 아니다.
4. 본문은 40px을 기준으로, 제목은 64px, 표지 88px, footer 24px을 기준으로 한다. 긴 문장을 숨기거나 아주 작은 글자로 압축하지 않는다. 각 회차의 실제 16:9 캡처에서 조정한다.
5. 화면 전환은 짧은 내부 등장 효과까지만 허용한다. `.slide`의 transform은 축척 엔진만 소유한다. `?export=1`과 동작 줄이기 설정에서는 정지 상태로 표시한다. 현재 구현은 전환 모션 없이 정적 지면을 사용한다.
6. 현재 강의 파일의 본문·발표 메모·출처 ID·시간·영상 링크를 테마 작업으로 수정하지 않는다. 새 회차에도 원본 콘텐츠와 화면 테마의 변경을 분리한다.
7. 로컬 초안과 QA를 먼저 보여주고, 사용자 수정 완료 확인이나 업로드 지시 후에만 GitHub push/PR/Pages 단계를 진행한다. 공개용 테마 자산이 포함돼도 강의의 공개 승인 해시와 비공개 자산 경계는 별도로 검사한다.

## 구현 위치와 검사

- 토큰·패턴: `src/themes/editorial/theme.css`
- 장식 원본: `src/themes/editorial/assets/collage.webp`
- 빌드 복사: `scripts/cli.mjs`
- 슬라이드 hook·차트 색: `src/presentation.js`
- 포트폴리오 hook: `src/portfolio.js`
- 검수: `npm run validate`, `npm test`, `npm run build`, `npm run qa -- --lecture <slug>`, `npm run export -- --lecture <slug>`, 공개 대상이면 `npm run build:public`과 승인 검사

CSS 배경 자산은 DOM의 정보 이미지 개수에 포함하지 않는다. 브라우저 QA는 표지의 단색 면과 포트폴리오 배경 파일의 decode·경로를 별도 확인한다. 문서의 이전 흰 배경·장식 제한은 위의 한정된 테마 결정과 함께 읽는다.
