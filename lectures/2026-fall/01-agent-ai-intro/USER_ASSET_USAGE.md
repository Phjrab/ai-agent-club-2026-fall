새 CLI 원본: `cli codex.png` → L01-S03, `cli claude.png` → L01-S04, `cli gemini.png` → L01-S05. 각 파일의 해시·해상도·권리 상태는 `assets.yaml`에 기록했다. Claude Code 화면에는 사용자 경로와 권한 설정 문구가 보여 공개 전 화면 범위를 다시 살핀다.

새 Remote 원본: `remote gpt 01.PNG`·`remote gpt 02.PNG` → L01-S25. 두 화면의 원본 바이트를 보존했고, 컴퓨터 이름·프로젝트명이 보이므로 `assets.yaml`에 개인정보 포함 상태를 표시했다. GitHub 로고는 Simple Icons의 배경 없는 SVG로 교체해 L01-S27과 L01-A03에 배치했다.

OpenAI 로고는 사용자가 제공한 투명 SVG를 그대로 사용한다. Claude·Gemini·Grok은 배경이 포함된 원본 대신 출처가 기록된 투명 벡터 아이콘을 사용한다. 세 아이콘의 출처와 수정 내용은 `assets.yaml`에 기록했다.

영상 연결은 파일명 번호가 아닌 실제 그림을 기준으로 확인했다. thumbnail 1.jpg → V01, thimbnail 3.jpg → V02, thumbnail 2.jpg → V03이다. codex cot.png는 추론 강도 설정 화면이며 내부 사고 과정의 캡처가 아니다.

11쪽 `codex usage.png`는 원본 1167×1007을 보존하고, 주간 한도·크레딧만 자른 `codex-usage-crop.png`(805×305)를 발표 화면에 사용한다. 크롭 사본의 해시·권리 기록은 `assets.yaml`에 있다.

추가 제공 로고 `logo kimi`는 PNG 형식으로 확인해 `logo-kimi.png`로 복사했다. `logo openclaw.jpeg`와 `logo perplexity.jpeg`는 원본 파일로 보존한다. 두 JPEG에는 체크무늬가 실제 픽셀로 들어 있어 L01-S06에는 배경 없는 공개 SVG 로고를 대신 배치했다. 사용 중인 SVG의 출처·해시·크기는 `assets.yaml`에 있다. `csu ai model list.png`는 원본을 그대로 남기고 모델 선택 목록 부분만 자른 `csu-models-crop.png`를 L01-A01에 사용한다.

추가 강의자료 `인공지능개론_3_염홍기.pdf`의 32쪽 권한 메뉴 예시는 로컬 검토용 PNG로 잘라 `.private/lecture-assets/lecture-claude-permission.png`에 보관하고 L01-S29에 배치했다. 공개 사용 권리가 확인되지 않았으므로 `publicAllowed: false`이며 공개 빌드에는 넣지 않는다. PDF 원본 전체를 저장소로 복사하지 않았다.
