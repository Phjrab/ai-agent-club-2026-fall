## 자산 집계

- 직접 만든 설명용 SVG 18개를 렌더링하고 실제 슬라이드에 배치했다.
- 사용자가 제공한 YouTube 썸네일 3장을 L01-S15에 16:9 비율로 배치했다. 첨부 자료는 전부 사용했다.
- 별도 웹 이미지·공식 로고·생성 이미지·실제 제품 앱 화면 캡처는 사용하지 않았다. 제품 화면처럼 보이는 이미지를 만들어 넣지 않고 직접 만든 도식을 사용했다.
- 실제 가격 페이지 화면은 사용자 제공 Safari 참조(U02)로만 기록했다. 이를 현재 앱 UI 캡처라고 표현하지 않았다.
- 썸네일의 원저작자·라이선스·공개 재배포 권한은 확인되지 않아 assets.yaml의 `publicAllowed: false`를 유지했다. 공개본 빌드에 들어갈 수 없다.
