# 이번 회차 수업 내용

이 문서의 YAML은 실제 정보로 바꾼다. 날짜·강의실을 모르면 `null`을 유지한다. 확정 회차에 맞춰 lecture_id와 slug를 고유하게 지정한다. 아직 채우지 않은 아래 설명 문구를 실제 수업 사실로 사용하지 않는다.

## 1. 수업의 한 문장 목표

[이번 수업을 마치면 무엇을 이해하거나 판단할 수 있어야 하는가?]

## 2. 청중과 발표자

청중: AI Agent 사용 경험이 많지 않은 대학생.

알고 있다고 가정해도 되는 내용: [기존 회차에서 배운 개념]

추가로 설명할 배경: [낯설 수 있는 용어·환경]

발표자 배경: 로봇·회로·AI 프로젝트 경험이 있으나, 이번 주제에서 학습이 더 필요한 항목은 [기재].

## 3. 발표 방식과 톤

강의식으로 진행하며 별도 실습 시간과 의무 과제는 없다. 관심 있는 도구는 수업 후 자율적으로 시도하는 방식이다. 쉽게 설명하고 상황형 비유·가벼운 유머를 제한적으로 사용할 수 있다.

## 4. 반드시 포함할 내용

각 항목에 고유 requirement ID를 붙인다. Codex는 이를 slide ID와 연결해 커버리지를 검사한다.

- REQ-01: [핵심 개념]
- REQ-02: [비교 기준 또는 구조]
- REQ-03: [실제 사용 방법]
- REQ-04: [실제 경험·실수·주의점]
- REQ-05: [정리·선택 기준]

## 5. 권장 설명 흐름과 시간

| 구간 | 설명할 내용 | 분 |
|---|---|---:|
| 시작 | 지난 수업과 연결, 이번 문제 | 3 |
| 개념 | 알아야 할 핵심 개념 | 10 |
| 구조·비교 | 무엇이 같고 다른가 | 10 |
| 사용 예시 | 화면·작업·프롬프트 사례 | 15 |
| 경험·한계 | 내가 겪은 점과 판단 기준 | 10 |
| 정리 | 한 문장씩 회수 | 2 |
| 질의응답 | 별도 운영 | 10 |

위 배분은 예시다. 수정 후 설명 합계와 질의응답 합계가 frontmatter와 일치해야 한다.

## 7. 참고 자료

원본 자료: [로컬 실제 경로·첨부 이름·공식 URL 또는 없음]

참고할 기존 발표: [경로 또는 없음]

반드시 사용할 Figure·표·수식: [위치·번호 또는 없음]

주의: 파일 이름만 있고 실제 파일에 접근할 수 없다면 내용을 추측하지 말고 불완전한 자료로 기록한다.

## 8. 수치·차트

비교하려는 값: [있을 때만]

원시 데이터/출처/조건/단위: [기재]

차트의 핵심 메시지: [무엇을 보여주는가]

수치가 없으면 정성 비교 표나 관계도로 설명한다. Chart.js를 쓰기 위해 점수나 성능 수치를 창작하지 않는다.

## 10. 아직 결정되지 않은 항목

[미정 내용을 실제 사실로 바꾸지 말 것]

## 11. 출력과 완료 기준

HTML 발표자료, PDF, visual PPTX, 한국어 대본 DOCX, 출처 목록, 콘텐츠 커버리지, 실제 QA 보고를 만든다. 콘텐츠는 처음에 draft다. 공개 승인 여부를 에이전트가 임의로 true로 바꾸지 않는다.

강의 자료의 품질을 바꾸는 추가 요구사항이 있으면 여기에 적는다. 이 파일만 수정해 push했다고 Codex의 집필 작업이 자동 수행되는 것은 아니며, 별도의 제작 프롬프트를 실행해야 한다.
